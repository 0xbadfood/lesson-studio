        Workflow

        Choose how chapters are animated and the model that makes each part of the lesson. Reviewers are set on the Reviews tab. New lessons use these choices; lessons already running keep the models they started with.

          Reviews

          Each reviewer has a model and the criteria it scores from 0 to 3 (0 wrong or missing, 1 serious problem, 2 small flaw, 3 right). The reviewer never decides pass or fail: a criterion below its minimum fails the review and goes back for a fix; a score below 3 that meets the minimum becomes a note. New lessons use these choices; saved configurations keep their own.

          Reviewer accuracy

          Every review score below its minimum is a finding that caused a retry. Mark each one right or wrong, or let the Review auditor (set on the Reviews tab) judge the backlog; your verdict always counts over the auditor's. A finding is wrong (a false positive) when the problem is not there, is only a difference of wording, stage, detail or style, comes from a frame caught mid-animation, or would not mislead a learner.

          Configurations

          A configuration is a saved set of model choices. Apply one to make it the current settings, or pick it per lesson on the New lesson form to compare configurations on the same topic.

          Runs by configuration

          Recent lessons with the configuration they ran, their model cost (as reported by OpenRouter; local models are free) and time.
